## 当前实现

- 新请求、规划、两类 CPU 执行、回料、保种、取消、link、存档均有独立 graph 链路。真实生产路径的旧核心计数为零。
- 独立有界线程池、公平工作片、可恢复构图/SCC/搜索/验证；软提示默认 2 秒，硬超时默认 0，搜索和内存限制独立。
- 多来源数量拆分、多输出统一次数、差分回滚、相关结构缓存和安全并行构图；未知/受限不冒充全局无解。
- Batch/Sequence/Repeat 压缩见证、精确 long / BigInteger、有限派发授权；实际在途、外部等待、恢复义务分账。
- schema 4 保存计划、剩余游标、流水线窗口、批次所有权、恢复阶段与已承诺历史；兼容读取 schema 1–3。
  运行中只重规划未承诺后缀，失败等相关事件唤醒。
- 图批量策略保留容量、能量和配置电路规则；保守预留的多余电路最终退款。

## 未完成的实现及验证

主要实现缺口是跨 CPU 闭合等待责任收集、隐藏回收输出专项诊断，以及部分特殊机器能力作用域的完整验证。
后备分配搜索是有预算的非完备算法，复杂问题可能返回 UNKNOWN/SEARCH_LIMIT；不承诺任意环都可求解或最优。
实际客户端、无线终端、GT 流体/工具/中继/异步输出队列和网络分裂等仍需游戏回归。
这些限制不由“能编译”“包能往返”或单个成功订单消除。
